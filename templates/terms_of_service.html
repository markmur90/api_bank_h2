1. Aceptación de los Términos

Al acceder y utilizar la API BanK, usted acepta estar sujeto a estos Términos de Servicio. Si no está de acuerdo con alguna parte de estos términos, no debe utilizar nuestro servicio.

2. Descripción del Servicio

API BanK es una plataforma que facilita la comunicación segura con instituciones financieras para la realización de transferencias SEPA y otras operaciones bancarias. Nuestro servicio incluye:

  • Gestión de transferencias bancarias
  • Autenticación OAuth2 segura
  • Generación de documentos XML y PDF
  • Monitoreo y logging de operaciones
  • Configuración dinámica de entornos

3. Uso Aceptable

Usted se compromete a:

  • Utilizar el servicio únicamente para fines legítimos y autorizados
  • No intentar acceder a sistemas o datos no autorizados
  • No interferir con el funcionamiento del servicio
  • Mantener la confidencialidad de sus credenciales
  • Cumplir con todas las leyes y regulaciones aplicables

4. Seguridad y Privacidad

Nos comprometemos a proteger la seguridad de sus datos mediante:

  • Encriptación de datos en tránsito y en reposo
  • Autenticación multifactor
  • Monitoreo continuo de seguridad
  • Cumplimiento de estándares bancarios

5. Limitaciones de Responsabilidad

API BanK se proporciona "tal como está" sin garantías de ningún tipo. No nos hacemos responsables de:

  • Pérdidas financieras derivadas del uso del servicio
  • Interrupciones temporales del servicio
  • Errores en la transmisión de datos
  • Uso no autorizado de credenciales

6. Modificaciones del Servicio

Nos reservamos el derecho de modificar o discontinuar el servicio en cualquier momento, notificando a los usuarios con anticipación razonable.

7. Terminación

Podemos suspender o terminar su acceso al servicio en caso de:

  • Violación de estos términos
  • Uso fraudulento o malicioso
  • Incumplimiento de regulaciones bancarias

8. Contacto

Para preguntas sobre estos términos, contacte a nuestro equipo de soporte.

Importante: Estos términos están sujetos a cambios. Le recomendamos revisarlos periódicamente.
